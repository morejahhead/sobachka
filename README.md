# Shoelace Chaos — vertical slice

Минимальный рабочий прототип браузерной 3D-игры про шнуровку кроссовка.

## Стек

- Three.js (рендер)
- cannon-es (rope physics + коллизии)
- JavaScript (ESM)
- Vite (dev server / сборка)

## Запуск

```bash
npm install
npm run dev
```

Открыть локальный URL от Vite (обычно `http://localhost:5173`).

## Что уже реализовано

- low-poly сцена с кроссовком
- люверсы как физические кольца (аппроксимация из сфер)
- шнурок как единый rope-объект из сегментов на constraints
- 2 эглета (концы шнурка)
- захват эглета мышью + перетаскивание в 3D
- после отпускания эглет фиксируется на месте (STATIC body)
- гравитация, коллизии с кроссовком/полом/люверсами
- orbit camera

## Почему `cannon-es`

Для вертикального среза это оптимум по времени/простоте:
- быстрый старт в браузере
- простые constraints для rope поведения
- стабильный open-source форк Cannon.js

Если пойдёте в продакшн и нужна точнее/реалистичнее rope-солвер физика, можно мигрировать на Rapier + кастомные joints/solver tweaks.
